# 🎮 Tic-Tac-Toe Game

This is a simple and interactive Tic-Tac-Toe game built using **HTML, CSS, and JavaScript**. The project focuses on implementing core frontend concepts and game logic in a clean and user-friendly interface.

---

## 🚀 Features

* ❌⭕ Two-player turn-based gameplay
* 🎯 Automatic winner detection
* 🌈 Different colors for X and O
* 🏆 Winner announcement display
* ✨ Highlight winning combination
* 🔄 Reset game functionality
* 🔊 Sound effect on click (optional enhancement)
* 🎨 Modern and responsive UI design

---

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
